# ComfyUI (w przygotowaniu)

Cel: generowanie teł, tekstur i miniatur (np. jesienny pejzaż pod klip Vivaldiego), które potem
wchodzą do renderu jako warstwy tła.

- Workflowy zapisujemy jako `comfyui/workflows/<nazwa>.json` (bez modeli – te są na udziale).
- Wywołanie z Pythona przez API ComfyUI (`comfyui_url` w `config/sciezki.toml`).

Do ustalenia: modele (np. SDXL / Flux), karta graficzna, licencje modeli do użytku na YouTube.
